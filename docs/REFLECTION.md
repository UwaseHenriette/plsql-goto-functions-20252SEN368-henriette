# Reflection

## What I Learned

Through this assignment, I learned how to use PL/SQL `GOTO` statements, stored functions, conditional statements, and exception handling.

I learned how to create a PL/SQL program that uses `GOTO` to move to different labeled sections. I also learned that some `GOTO` statements are illegal and how to rewrite the program without using `GOTO`.

I learned how to create stored functions for calculating annual salary, years of service, tax calculator, and department name. I also learned how functions can be used directly inside SQL `SELECT` statements.

The Payroll Validator helped me understand how exception handling can be used to handle situations such as an employee not being found.

## Challenges

One challenge I faced was understanding how `GOTO` labels work in PL/SQL. I also had to understand how functions receive parameters and return values.

Another challenge was testing the functions with the employee data in my database. I solved these challenges by running the programs step by step and checking the output.

## Conclusion

This assignment improved my understanding of PL/SQL programming. I can now create and test `GOTO` statements, stored functions, and functions used in SQL. I also understand better how PL/SQL can be used to solve problems in a database system.
